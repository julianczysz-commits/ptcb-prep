# PTCB App Features

## MVP Goal

Build a simple but engaging PTCB study app that helps users prepare for the exam through short lessons, quizzes, and gamification.

## User Features

### Account
- Create an account
- Log in
- Track personal progress

### Learning
- View lessons
- Answer multiple-choice questions
- Receive instant feedback
- See explanations after answers

### Progress Tracking
- Track completed lessons
- Track quiz accuracy
- Show exam readiness progress

### Gamification
- Earn XP points
- Level up
- Maintain daily streaks
- Unlock achievements

## Learning Style

Lessons should be:
- Short (1-5 minutes)
- Interactive
- Easy to understand
- Focused on one concept at a time

## Design Style

The app should feel like:
- Duolingo for learning
- TikTok for engagement
- Kahoot for quizzes

The design should include:
- Smooth animations
- Large buttons
- Clear progress indicators
- Positive feedback

## MVP Content

The first version should include:
- One PTCB subject category
- Practice questions
- Basic progress tracking
- XP system
