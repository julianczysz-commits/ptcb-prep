# PTCB Learning App Vision

## Mission
Create the most engaging way to study for the Pharmacy Technician Certification Board (PTCB) Exam.

## Product Idea
A Duolingo-style learning app combined with TikTok-style engagement and Anki-style memory techniques.

The app should make studying feel like a game instead of traditional studying.

## Target User
People preparing for the PTCB Exam.

## Core Experience
Users should:
- Complete short lessons
- Answer interactive questions
- Earn XP
- Maintain daily streaks
- Track progress toward exam readiness

## Design Inspiration
The experience should be inspired by:
- Duolingo (gamification and progression)
- TikTok (fast, engaging content)
- Kahoot (interactive questions)
- Apple Fitness (progress tracking)

## Important Principles
- Lessons should be short
- Feedback should be instant
- The app should feel energetic and rewarding
- Users should want to return every day
